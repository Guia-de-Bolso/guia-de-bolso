# Security

**English** · [Português abaixo](#segurança)

Report vulnerabilities to **contato@guiadebolso.app** (subject: `Guia de Bolso — security`).

Do **not** open public GitHub issues with exploit details, payloads, or steps that would help an attacker.

Please include:

- Affected surface (web, iOS, Android, API, RLS)
- Impact (data exposure, privilege escalation, quota bypass)
- Reproduction **after** we reply, or a high-level description first

We aim to acknowledge reports within a few business days.

Row Level Security and migration order: [`docs/security-rls.md`](docs/security-rls.md) · [`SECURITY_CHECKLIST.md`](SECURITY_CHECKLIST.md).
